VAULTFALL — The Meridian Heist: a top-down stealth heist roguelite. Cross 5 guarded floors, dodge vision cones and sweeping cameras, crack vaults, face Warden Vex and Sentinel Prime, choose relics between floors and build your hideout. WASD move, Shift sneak, Space hold to interact, mouse click decoy coin, E EMP, Q smoke.

## Run it

```sh
node serve.ts   # then open http://localhost:8080
```
